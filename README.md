# Hospitalito

Sistema Digital de Historia Clínica. Versión de prueba actual: **v283**, basada en v282.

- [Abrir la aplicación](https://walterRigoni.github.io/hospitalito/)
- [Archivo HTML v283](Hospitalito_v283.html)
- [Guía de cambios y configuración](Hospitalito_v283_guia.md)

La guía incluye los registros de Hemoterapia, permisos de servicios, archivos de consentimientos, logos, chat y avisos. El relevo TURN para videollamadas entre redes distintas está preparado y pendiente de configuración. La integración de IA es una posibilidad futura y todavía no está activa.

El directorio `supabase` conserva las funciones y migraciones del servidor; `tests` contiene las comprobaciones de historia, prescripciones, sincronización, avisos y permisos. Las credenciales permanentes permanecen en el servidor.
